
Student Grade Calculator

A beginner-friendly C++ project to calculate student marks, percentage, and grades.

Features

- Accepts marks for 5 subjects
- Calculates total marks and percentage
- Displays pass or fail status
- Assigns a grade based on percentage
- Validates marks between 0 and 100

Concepts Used

- C++ basics
- Arrays and loops
- Conditional statements
- User input and output

How to Run

Compile using a C++ compiler:

"g++ student-grade-calculator.cpp -o calculator"

Run the program:

- Windows: "calculator.exe"
- Linux/macOS: "./calculator"

Learning Goal

Practicing C++ fundamentals through a simple academic project.
